# 功能演示指南

## 🎯 新功能概览

本次优化为您的 TTS 应用添加了两个重要功能：

1. **音频时长显示** - 每个历史记录卡片现在都会显示音频的精确时长
2. **增强的交互设计** - 新的菜单系统和删除功能

## 🎵 音频时长显示

### 功能特点
- ✅ **精确时长** - 使用 mutagen 库获取音频文件的真实时长
- ✅ **智能格式化** - 自动转换为易读格式（如 "2m30s"、"45s"）
- ✅ **错误处理** - 无法获取时长时显示 "未知"

### 显示位置
时长信息显示在历史记录卡片的左下角，与播放次数并列显示：

```
🎧 3    🕐 2m30s
```

## 🎮 新的交互设计

### 按钮布局
每个历史记录卡片现在有两个按钮：

1. **播放/暂停按钮** (左侧)
   - 圆形按钮，36x36px
   - 点击播放音频，再次点击暂停
   - 播放时显示 ⏸️ 图标

2. **菜单按钮** (右侧)
   - 圆形按钮，32x32px
   - 显示 "⋯" 符号
   - 点击显示下拉菜单

### 菜单功能
点击菜单按钮会显示下拉选项：

```
┌─────────────┐
│ 🗑️ 删除     │
└─────────────┘
```

### 删除功能
1. 点击 "🗑️ 删除" 选项
2. 系统显示确认对话框：
   ```
   确定要删除这条历史记录吗？此操作不可撤销。
   ```
3. 确认后：
   - 从 history.json 中删除记录
   - 从 history_audio/ 目录删除音频文件
   - 卡片平滑淡出并移除
   - 显示成功消息

## 🚀 使用方法

### 1. 启动应用
```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务器
python app.py
```

### 2. 合成音频
1. 在文本框中输入内容
2. 选择音色
3. 点击 "合成播客" 按钮
4. 等待音频生成完成

### 3. 查看历史记录
- 音频合成完成后会自动出现在历史记录中
- 每个卡片显示：
  - 脚本预览
  - 音色名称
  - 播放次数
  - **音频时长** (新功能)
  - 播放/暂停按钮
  - 菜单按钮

### 4. 播放音频
- 点击播放按钮开始播放
- 再次点击暂停播放
- 播放次数会自动增加

### 5. 删除记录
- 点击菜单按钮 (⋯)
- 选择 "🗑️ 删除"
- 确认删除操作

## 🔧 技术细节

### 后端 API
- `POST /synthesize-audio` - 合成音频并获取时长
- `GET /history` - 获取历史记录
- `POST /history/play/<id>` - 增加播放次数
- `DELETE /history/<id>` - 删除历史记录 (新功能)

### 前端特性
- 响应式设计，适配各种屏幕尺寸
- 平滑动画效果
- 智能播放控制（同时只能播放一个音频）
- 完整的错误处理和用户反馈
