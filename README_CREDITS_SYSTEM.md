## 功能特性

### ✅ 已实现功能
- **原子化扣分**：音频合成与积分扣除在同一事务中完成
- **余额校验**：合成前检查积分余额，不足时返回 402 错误
- **自动积分刷新**：合成成功后前端自动更新积分显示
- **事务安全**：任何步骤失败都会回滚，确保数据一致性
- **环境变量配置**：支持通过环境变量配置积分消耗

### 🔧 核心机制
1. **预检机制**：音频合成前检查积分余额
2. **原子化操作**：生成音频 → 写历史 → 扣分 → 提交
3. **失败回滚**：任一步骤失败则整个事务回滚
4. **前端同步**：合成成功后自动刷新积分显示

## 配置说明

### 环境变量
在 `.env.local` 文件中配置：
```bash
# 积分系统配置
CREDITS_PER_AUDIO=10  # 每次音频合成消耗的积分数

# SiliconFlow TTS 配置
SF_TTS_MODEL=fnlp/MOSS-TTSD-v0.5
SF_TTS_MAX_TOKENS=16384
SF_TTS_FORMAT=mp3
```

### 数据库字段
系统会自动添加以下字段：
- `credits`：用户积分余额（默认 30 分）
- `plan`：用户订阅计划
- `stripe_customer_id`：Stripe 客户 ID
- `stripe_subscription_id`：Stripe 订阅 ID

## API 接口

### 音频合成接口
**POST** `/synthesize-audio`

**请求参数：**
```json
{
    "script": "播客脚本内容",
    "voiceName": "音色名称",
    "mode": "播客模式",
    "title": "播客标题",
    "originalInput": "原始输入内容",
    "inputType": "输入类型"
}
```

**成功响应：**
```json
{
    "id": "音频ID",
    "title": "播客标题",
    "script_full": "脚本内容",
    "audio_filename": "音频文件名",
    "timestamp": "创建时间",
    "mode": "播客模式",
    "voice_name": "音色名称",
    "duration": "音频时长",
    "play_count": "播放次数",
    "thumbnail_filename": "缩略图文件名",
    "original_input": "原始输入",
    "input_type": "输入类型",
    "credits": 20  // 最新积分余额
}
```

**积分不足响应（402）：**
```json
{
    "error": "积分不足",
    "required": 10,
    "current": 5,
    "payment_required": true
}
```

### 用户状态接口
**GET** `/api/user/status`

**响应：**
```json
{
    "isLoggedIn": true,
    "user": {
        "username": "用户名",
        "email": "邮箱",
        "credits": 20,
        "plan": "free",
        "is_verified": true
    }
}
```

## 使用流程

### 1. 用户登录
用户必须先登录才能使用音频合成功能。

### 2. 检查积分余额
系统会在合成前自动检查积分余额。

### 3. 音频合成
如果积分充足，系统会：
1. 生成音频文件
2. 创建历史记录
3. 扣除相应积分
4. 返回合成结果

### 4. 积分不足处理
如果积分不足，系统会：
1. 返回 402 状态码
2. 提供详细的错误信息
3. 建议用户充值

## 故障排除

### 常见问题

#### 1. 积分未扣除
- 检查数据库事务是否正常提交
- 查看后端日志中的错误信息
- 验证用户对象是否正确更新

#### 2. 前端积分不更新
- 检查 `refreshCreditsDisplay()` 函数是否被调用
- 验证 API 响应中是否包含 `credits` 字段
- 查看浏览器控制台的错误信息

#### 3. 环境变量未生效
- 确认 `.env.local` 文件存在且格式正确
- 检查 `python-dotenv` 是否正确安装
- 重启应用程序以加载新的环境变量
